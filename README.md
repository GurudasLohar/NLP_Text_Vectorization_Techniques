# Text Vectorization Assignment

## File
Text_Vectorization.ipynb

## Dataset
Same 25 cleaned product-review texts from previous NLP assignment.

## Tasks
1. Manual one-hot encoding
2. One-hot with CountVectorizer(binary=True)
3. Bag of Words (CountVectorizer)
4. Word frequency (top/least)
5. Unigrams, bigrams, trigrams
6. Combined n-grams (1,2)
7. TF-IDF vectorization
8. BoW vs TF-IDF comparison
9. max_features, min_df, max_df exploration
10. Conceptual answers

pip install scikit-learn pandas numpy
